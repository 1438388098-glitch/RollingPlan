# RollingPlan

一个 PyQt5 桌面应用，实现「计划自动滚动分配」功能。

> **接手 / 新会话先读 [`STATE.md`](STATE.md)**：当前版本、分支与推送状态、测试怎么跑、
> 还没做完的事、以及一堆踩过的坑都记在那儿。本 README 只讲「是什么 + 怎么用」。

### v0.12
- **额外轮 = 当天额外的时间栏**：额外加进来的子计划在额外轮里按顺序候补。

  - 对照：没拦截 → 早2 中3 晚4（4 顶进最后一格）；固定（不是拦截）→ 也不冻结额外轮
- **「📋 额外安排（N）」细长条按钮**：放在「➕ 加一个 / ✓ 今天完成」上方，
  长度 = 那两个按钮合起来的跨度，但更矮（30px vs 53px）；
  今天有格子拦截时按钮上会标「· 已拦截」
- **点开是当天额外安排列表**（对话框）：
  - 每条：`1. 计划内容` + 状态（`候补中` / `已滚入今天的第 N 格`）+ **「🗑 删除该安排」**

    **「⤵ 直接拉取下一个」**（不挑，按顺序直接拉下一条）、关闭

### v0.11
- **每个时段栏加两个小按钮**：
  - **固定计划**：按下后这一格的原定计划**不参与前面时间栏触发的上滚**（它后面的照常参与）
    - 例：早1 中2 晚3，固定「中」，点「早 → 完成并滚动」→ 早3 **📌中2** 晚空（中的 2 没动，晚的 3 挤到早）
  - **拦截滚动**：按下后这一格**及往后**都不参与上滚
    - 例：同上但拦截「中」→ 早空 📌中2 📌晚3（中晚都锁住，早空出来的位置没人补）
    - 拦截「晚」→ 早2 中空 ⛔晚3（晚不动，中的 2 挤到早）
  - 两个都是可切换的小按钮，按下时行首显示 📌 / ⛔ 标记；再按一次取消
  - 腾出来的位置仍然**只由额外轮补**（不会从第二天拉计划）
- 完成的格子会顺手解开它的固定/拦截（不然它一直占着不动）
- 固定 / 拦截随天切换归零（它们是「今天」的设置）
- 新增 `test_scroll_v11.py`：覆盖 v0.9~v0.12 全部滚动语义（现 165 断言）

## 功能

- **母计划**：可多个并行（"工作"、"学习"、"健身"...）
- **子计划**：每个母计划下有自己的子计划列表
- **时间段**：可自定义数量和名称（如"早/中/晚"或"上午/下午/晚上"或"白天/晚上"）
- **执行**：当天时间段展示 + 额外轮（额外加进来的计划在这里按顺序候补）
- **额外安排列表**：点「📋 额外安排」细长条按钮打开 —— 当天额外安排一览，
  可逐条「🗑 删除该安排」、「➕ 添加指定计划」、「⤵ 直接拉取下一个」
- **拦截滚动连带额外轮**：按了「拦截滚动」，额外轮（当天最后的时间栏）也在拦截范围里
- **借指定时间段**：弹对话框选择"今天借哪个时间段"，会从最靠前的未借走的同名槽位借
- **链式借**：明天借空了就从后天借
- **退回**：把额外轮最后 1 个推回去（今天有完成过时，「退回」先用来撤销完成）
- **仅完成**：今天某一格点「仅完成」→ 标记完成、记进该时段备注，后面的计划不滚动
- **完成并滚动**：点「✓ 完成并滚动」→ 归档这一格、后面的整体上滚一格；腾出来的最后一格只由额外轮补
- **固定计划 / 拦截滚动**：每一格两个小按钮 —— 固定住这一格（它不上滚，后面的照常）、
  或从这一格起拦截滚动（这一格及往后都不上滚）
- **时段只是栏位**：时段名只表示「当天第几格」，不代表计划本身；额外轮里的计划不带时段名
- **主题**：暗色 / 亮色 / 跟随系统，自写 QSS，实时切换并跨会话记住
- **快捷键**：Ctrl+1/2/3 切换三个页面；执行页内 Ctrl+Enter 加一个 / Ctrl+D 结束今天 / Ctrl+Z 撤销 / Ctrl+Shift+Z（或 Ctrl+Y）重做
- **撤销 / 重做栈**：加一个、退回、仅完成、完成并滚动、固定、拦截、**切天**都能撤，最多 50 步；有可撤动作时「↶ 撤销 / ↷ 重做」会显示在主按钮行上方
- **第三页「📊 归档总览」**：进度 + 「还剩 N 条 ≈ 还要 N 天」估算 + 归档历史（按天分组、可折叠）+
  今天完成 + 各时段归档备注；下拉可切单个分类，也可以选「（全部分类）」看全局
- **「⬇ 导出归档」**：把归档写成 .txt（按天分组 + 今天完成 + 时段备注 + 估算）；
  在「（全部分类）」下会把所有分类拼成一个文件
- **数据存储**：INI 文件（`%APPDATA%\RollingPlan\Data.ini`），每次保存自动轮转保留 3 代备份；编辑页「⋯」可一键「♻️ 恢复上次备份」；读档失败会弹窗并把损坏数据转存备份文件

## 界面（极简口径）

v0.26~v0.28 把界面按「**主操作常驻、次要点开才有**」重排过一轮。默认视图里只留每天真要按的东西：

**执行页**（天天用的一页）
- 顶栏：只有「更多」+ 当前分类名
- 中间：`📅 第 N 天`，下面一行小字 `进度 4/5 · 今天完成 1 条`（完成了什么在 hover 的 tooltip 里）
- 每一格是一张卡片：时段名 + 计划内容 + **一个**「✓ 完成并滚动」+ 一个「⋯」（更多操作菜单）
  - **右键这一行或点「⋯」** = 仅完成 / 固定计划 / 拦截滚动 / 完成并滚动
- 底部：`➕ 加一个`、`⏭ 结束今天 →`（进入下一天，未完成会提醒）；最下面一行 `计划队列 · 还有 N 条`（点开才展开）
- 「📋 额外安排」按钮**只在真有额外安排时才出现**（0 条时完全不显示）
- 收进「更多」的：切换分类 / 主题 / 返回制定 / 退回 / 撤销 / 重做 / 添加指定

**制定页**
- 常驻：标题、主题下拉、右上「⋯」
- 四组（计划分类 / 计划清单 / 时段 / 起始日期）都以 `▸` 收起，点标题展开
- 底部常驻：`生成计划`、`开始执行 →`
- 收进「⋯」的：重置进度 / 导入 JSON / 导出 JSON / 预览；**预览区点了「预览」才出现**

**归档总览页**
- 常驻：标题、分类下拉、右上「⋯」
- `📈 进度`（含「还剩 N 条 ≈ 还要 N 天」）
- `🗂 归档历史`：按天分组，点「📅 第 N 天」标题收起 / 展开
- `✅ 今天完成`：**今天什么都没完成时整块不出现**
- 收进「⋯」的：导出归档 / 全部展开·收起

**原则（改界面前先看这条）**：主操作常驻 → 次要入口收进 `⋯` 或 `▸` 折叠 → 0 条的东西不显示 →
能用 tooltip 说清的不占版面。
（**动作不删、入口收起来**：所有按钮对象都还在，隐藏之后快捷键 / 右键菜单 / 测试仍能触到。）

**动效原则（v0.29）**：动效只为「状态变了」服务 —— 切页淡入 / 折叠展开·收起 / 完成并滚动·切天·切分类
轻反馈 / 新内容（额外安排按钮·今天完成·预览区）浮现 / 对话框弹出；撤销、固定、拦截这类操作**不加动**。
统一 `animations.py` 收口：OutCubic + 150~220ms，动完即摘特效；
`QT_QPA_PLATFORM=offscreen` 下全部自动禁用（headless 测试与文字 dump 的行为和没有动效时逐字节一致）。

## 核心逻辑

见 `scheduler.py` 的 `PlanScheduler`：
- `pending()`：待办队列（`plans` 去掉已完成的）
- `today_state()`：今天的行 / 每格是否已完成 / 归档备注 / 额外轮 / 队列走到哪，一次算清
- `get_day_plans(day_index)`：取第 N 天的显示切片
- `get_calendar()` / `raw_calendar()`：执行页日历（从今天往后） / 制定页预览（整段铺开）
- `complete_only_slot(slot_idx)`：仅完成（不滚动）
- `complete_today_slot(slot_idx)`：完成并滚动（归档 + 上滚）
- `can_complete_only()` / `can_complete_today_slot()`：上面两个能不能点
- `undo_complete()` / `can_undo_complete()`：撤销今天最近一次完成（两种都算）
- `toggle_fixed(slot_idx)` / `toggle_blocked(slot_idx)`：固定计划 / 拦截滚动（可切）
- `borrow_next()` / `borrow_plan(计划)`：加一个 / 添加指定（进额外轮）
- `available_pick_plans()`：添加指定的候选（后面还没安排的计划，去重）
- `borrow_slot(name)` / `available_borrow_names()`：v0.3~v0.8 的按时段名入口，UI 已不用（保留给旧调用和回归测试）
- `return_last_borrowed()`：退回额外轮最后一个
- `get_progress()`：进度（已推进 / 总数，完成的也算）
- `all_consumed()`：判断全部完成
- `undo()` / `redo()`：走 `ParentPlan` 的撤销栈（v0.16）

其它模块：
- `rollingplan.py`：`ParentPlan` / `PlanData` / `MainWindow`（+ 撤销栈、`daily_boundaries` 收敛）
- `executor.py`：`PlanExecutor`（执行页）、`ExtraArrangementsDialog`（额外安排列表）
- `editor.py`：`PlanEditor`（制定计划页）
- `calendar_view.py`：`PlanCalendarView`（归档总览页）+ 纯函数
  `build_archive_text` / `build_all_archive_text` / `estimate_days_left` / `summarize_all` / `safe_filename`
- `theme.py`：三套 QSS + `apply_theme`
